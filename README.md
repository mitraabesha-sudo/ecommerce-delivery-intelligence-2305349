# E-Commerce Delivery Intelligence

## End-to-End Databricks and Snowflake Analytics Pipeline

### Project ID
2305349

## Project Overview

This project implements an end-to-end e-commerce delivery analytics pipeline using Databricks and Snowflake.

The project processes e-commerce data through Bronze, Silver, and Gold layers in Databricks and loads the final analytical datasets into Snowflake for business intelligence and reporting.

## Technology Stack

- Databricks
- Apache Spark / PySpark
- Delta Lake
- Snowflake
- Python
- SQL
- Streamlit
- GitHub
